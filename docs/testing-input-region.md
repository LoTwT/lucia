# 透明区域点击穿透验收

日期：2026-11-14。行为与精度约束由[桌宠规格](specs/desktop-pet.md#窗口形态)维护，本文只记录验证证据。

## 环境与构建

- macOS 27.2（26B123）、Apple M1 Pro、1512×982 DIP 单屏、2× 缩放；AX 自动化和屏幕捕获权限已授予。
- MyGo v0.9.0；基于 `bedb5841d77fee99afc1128d16b8100d04d1dd85` 加本次工作区改动。验收使用独立的 `Lucia Input QA X66BLW` 应用、数据目录和标识，关闭更新源。
- 三个变更的运行时文件及 `go.mod` 与实际构建导出逐字节核对；SHA-256、鼠标事件、窗口边界及性能采样保存在[原始记录](references/input-region-20261114.json)。测试期间未修改正式版和开发版的数据。
- 底层接收窗口是另一个进程的原生 AppKit 应用，记录实际收到的鼠标事件。测试前关闭 Lucia 控制台，保证接收窗口位于桌宠下方。

## 结果

| 项目 | 结果 |
|---|---|
| 透明边距 | 点击、右键、滚轮均由底层独立应用收到。 |
| 可见角色交互 | 点脸触发气泡，点击未传给底层；角色右键菜单可打开。 |
| 角色拖动 | 从衣领处拖动，窗口由 `(600,350)` 移至 `(690,290)`；底层未收到该次按下。 |
| 底层拖动 | 从透明角落开始，拖进角色范围后仍由底层收到连续拖动和松开；桌宠未移动。 |
| 四档尺寸 | 198、248、310、372 DIP 下，透明角落均穿透、脸部均截获；底边中点保持 `(814,538)`。 |
| 隐藏/恢复 | 隐藏后原脸部位置可点击底层；显示后同一位置重新由桌宠截获。 |
| 动画轮廓与内部空洞 | 临时三帧无损 WebP 包按“左侧实心区域→右侧实心区域→全透明”循环，带 `bob` 位移；左右命中随帧切换，两侧内部空洞都能穿透，全透明帧两侧均穿透。 |
| 运行中换包 | 内置包切至临时包再切回，输入区域跟随新模型，脸部命中恢复。临时包无热区，动画结果不依赖 UI 点击层。 |

临时包、生成器、GUI 自动化和辅助应用仅用于本次验收，不进入产品或 CI。验收结束后测试进程均已退出。

## 回归与编译检查

- `CGO_ENABLED=0 go test ./...`、`go vet ./...`、`go tool mygo vet .` 通过。
- `go test -race ./internal/pet ./cmd/lucia` 通过；补充的热区位移测试与修正后的测试夹具另做了定向竞态复测。
- 新测试覆盖透明空洞、极低 alpha、非零图像原点与 stride、Contain/位移/裁剪/缩放、复用缓冲区跳帧、全透明帧、碎片区域上限、实际视图选帧、Reduce Motion 海报和热区随立绘移动。
- macOS 原生应用打包、Windows/amd64 无 cgo 交叉编译通过。

## 性能短时观测

内置包在换包回归后采样，控制台关闭、鼠标静止；每组约 10 秒、每秒一条，共 10 条，未剔除任何样本。CPU 由 `ps` 的累计进程 CPU 时间差除以实际采样间隔计算，100% 表示占用一个逻辑核心；内存为 `ps rss` 换算的 MiB。

| 状态 | 平均 CPU | 最高 CPU | RSS（MiB） |
|---|---:|---:|---:|
| 内置包可见 | 6.23% | 8.89% | 174.06 |
| 桌宠隐藏 | 0.20% | 0.99% | 172.59–177.22 |

这些短时样本没有显示内置包的明显性能异常；没有本轮同条件的旧实现对照，不能据此计算功能开销。RSS 不等于物理内存足迹或 Go 堆；本次未重测大型 naiwa 包和长时间运行，先前超过 300 MB 的样本仍以[升级验收记录](testing-mygo-0.9.md#性能观测)为准。

## 未覆盖范围

Windows 真机依项目所有者决定在本阶段跳过；交叉编译不能证明 Windows 的原生命中和高 DPI 行为。Reduce Motion 已做视图测试，未切换系统偏好做实机复测；本次也未覆盖跨屏切换、极碎片素材的原生表现和高频移动鼠标的持续 CPU 成本。Linux 不在当前发布矩阵。
